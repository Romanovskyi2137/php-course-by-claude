# GLOSSARY.md — англійські терміни та їх переклад

Наскрізний словник. Кожен термін додається один раз, при першій появі в
конкретному `lecture.md`, і копіюється сюди. Формат: **Term (переклад)** — коротке пояснення.

Поповнюється по темах у процесі генерації курсу.

> Терміни з блоків A (01-10) і B (12-21) сюди ще не занесені заднім
> числом — словник почав вестись з блоку C. Якщо потрібно — можна
> донаповнити пізніше окремим проходом по вже написаних `lecture.md`.

## Блок C — стандартна бібліотека

- **Iterator (ітератор)** — вбудований інтерфейс з методами `current()`,
  `key()`, `next()`, `rewind()`, `valid()`; об'єкт, що його реалізує,
  можна перебирати через `foreach` (22).
- **Generator (генератор)** — об'єкт, який автоматично створює PHP, коли
  функція містить `yield`; реалізує `Iterator` за тебе (22).
- **`yield from`** — делегування ітерації іншому `iterable` зсередини
  генератора (22).
- **SPL (Standard PHP Library)** — набір вбудованих структур даних і
  інтерфейсів (`SplStack`, `SplQueue`, `SplObjectStorage` тощо),
  доступний без Composer (22).
- **`DateTimeImmutable`** — незмінний об'єкт дати/часу; будь-яка "зміна"
  повертає новий об'єкт (23).
- **`DateInterval`** — проміжок часу у форматі на кшталт `P1D`, `PT30M`
  (23).
- **`DateTimeZone`** — часовий пояс; визначає локальне представлення
  моменту часу й враховує DST (23).
- **Unix timestamp** — кількість секунд з 1 січня 1970 UTC, без прив'язки
  до часового поясу (23).
- **PCRE-роздільники (delimiters)** — символи навколо regex-патерну
  (`/.../`), що позначають його межі (24).
- **Named capture group (іменована група захоплення)** — `(?<name>...)`
  у регексі — дає збігу ім'я замість числового індексу (24).
- **Greedy vs lazy (жадібний і лінивий квантифікатор)** — `.*` бере
  максимально можливий збіг, `.*?` — мінімально можливий (24).
- **`JsonSerializable`** — інтерфейс з методом `jsonSerialize()`, що
  керує форматом об'єкта при `json_encode()` (25).
- **`JSON_THROW_ON_ERROR`** — прапорець, що змушує `json_*`-функції
  кидати `\JsonException` замість мовчазного `false`/`null` (25).
- **Stream (потік)** — узагальнений PHP-механізм вводу/виводу; той самий
  `fopen()`/`fgets()`-API працює для файлів, `php://stdin`,
  HTTP-з'єднань тощо (26).

## Блок D — веб-фундамент

- **SAPI (Server API)** — інтерфейс, через який PHP-рушій спілкується з
  сервером; `cli`, `cli-server`, `fpm-fcgi` — різні SAPI, той самий
  мовний рушій (28).
- **`php-fpm` (FastCGI Process Manager)** — пул PHP-процесів-воркерів,
  яким nginx передає запити через FastCGI; типова продакшн-конфігурація
  (28).
- **Front controller (єдина точка входу)** — патерн, де весь HTTP-трафік
  проходить через один файл (`index.php`), який далі маршрутизує запит
  (28).
- **Superglobal (суперглобальна змінна)** — масив, доступний у будь-якому
  скоупі без `global`: `$_GET`, `$_POST`, `$_SERVER`, `$_SESSION` тощо
  (29).
- **`php://input`** — потік для читання "сирого" тіла запиту; єдиний
  спосіб дістати JSON/XML-тіло, яке PHP не парсить автоматично (29).
- **PRG (Post/Redirect/Get)** — патерн: POST-обробник відповідає
  редіректом, а не HTML напряму, щоб оновлення сторінки не повторювало
  відправку форми (30).
- **`$_FILES`** — суперглобал зі структурою завантажених файлів (`name`,
  `type`, `tmp_name`, `error`, `size`) (30).
- **MIME sniffing (визначення типу за вмістом)** — визначення реального
  типу файлу за байтами (`finfo`), а не за заявленим клієнтом `type`
  (30).
- **Session (сесія)** — дані відвідувача, що живуть на сервері; клієнт
  тримає лише session ID у куці (31).
- **`HttpOnly`** — прапорець куки, що робить її недоступною з JS —
  захист від крадіжки session ID через XSS (31).
- **`SameSite`** — прапорець куки, що обмежує її надсилання при
  кросдоменних запитах — вбудований захист від CSRF (31).
- **Session fixation (фіксація сесії)** — атака через нав'язаний наперед
  session ID; захист — `session_regenerate_id()` при зміні привілеїв
  (31).
- **Salt (сіль)** — випадкові дані, вбудовані в хеш пароля, що роблять
  однаковий пароль різним хешем щоразу (32).
- **Timing attack (атака за часом)** — вгадування секрету за часом
  порівняння рядків; захист — `hash_equals()` (32).
- **XSS (Cross-Site Scripting)** — впровадження чужого JS через
  невиведений безпечно користувацький ввід (33).
- **CSRF (Cross-Site Request Forgery)** — примушення браузера жертви
  виконати дію на сайті, де вона автентифікована, без її відома (33).
- **Mass assignment (масове присвоєння)** — вразливість, коли весь
  вхідний масив без білого списку йде напряму в сутність (33).
- **CSP (Content Security Policy)** — HTTP-заголовок, що обмежує
  джерела, з яких браузер виконує скрипти/стилі (33).
