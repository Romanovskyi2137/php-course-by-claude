# PHP-курс

Інтерактивний курс PHP у вигляді файлів: код + пояснення + завдання з автоперевіркою.
Немає застосунку, який треба запускати, — є теми-папки, які ти проходиш по черзі,
а роль викладача виконує AI (або людина-ментор), з яким ти обговорюєш теорію
й розбираєш підказки.

**Для кого цей курс.** Ти вже вмієш програмувати іншою мовою (JS/Python/Java/...)
і розумієш базові концепції (змінні, цикли, функції, класи). Курс не пояснює
що таке змінна — він пояснює, чим PHP відрізняється і як влаштований саме він:
синтаксис, типова система, ООП-модель, стандартна бібліотека, веб-специфіка,
робота з БД і професійні практики.

## Встановлення

```bash
sudo apt-get update
sudo apt-get install -y php8.3-cli php8.3-mbstring php8.3-xml php8.3-mysql php8.3-intl php8.3-curl php8.3-sqlite3
php -v
```

Composer знадобиться пізніше (з теми `38-composer-and-psr4`), MySQL через Docker —
ще пізніше (з теми `35-databases-and-sql-essentials`). Детальні інструкції для
обох — у [`_env/README.md`](_env/README.md).

## Як влаштована кожна тема

```
NN-kebab-case-topic/
  lecture.md      # теорія з анотованими прикладами коду
  task.md         # що зробити, вимоги, контракт, як перевірити, підказки
  starter.php     # каркас із TODO — тут ти пишеш код
  check.php       # запускається як `php check.php`, автоматично перевіряє starter.php
  solution.php    # референсний розв'язок — відкривай тільки після зеленого check.php
```

Теми з web/DB-блоків можуть додатково мати `public/`, `templates/`, `data/`.

Повний список тем, блоки й прогрес — у [`CURRICULUM.md`](CURRICULUM.md).
Наскрізний словник термінів — у [`GLOSSARY.md`](GLOSSARY.md).

## Робочий процес для однієї теми

1. Прочитай `lecture.md`.
2. Прочитай `task.md` — особливо розділи «Вимоги» та «Контракт».
3. Редагуй `starter.php`, поки не позникають `RuntimeException('Не реалізовано')`.
4. Запусти перевірку:
   ```bash
   php check.php
   ```
5. Якщо застряг — розгорни підказки в кінці `task.md` по черзі, а не всі одразу.
6. Коли `check.php` зелений — **обов'язково** відкрий `solution.php` і порівняй
   свій підхід із референсним. Це не необов'язковий бонус, а частина теми.
7. Заціни чекбокс теми в `CURRICULUM.md` і зроби коміт:
   ```bash
   git add -A
   git commit -m "topic NN: <тема> — done"
   ```

Checkpoint-проєкти (`NN-checkpoint-*`) проходяться так само, тільки замість
`lecture.md` там `README.md` з брифом проєкту, а `starter.php`/`solution.php` —
це папки `starter/`/`solution/`.

## Дисципліна self-check

`check.php` для тем 01–43 не має зовнішніх залежностей і працює одразу після
встановлення PHP. З теми `44-testing-with-phpunit` перевірки переходять на
реальний PHPUnit — команда лишається та сама (`php check.php`), просто під
капотом зʼявляється `vendor/bin/phpunit`.

Для тем із БД (блок E/F) `check.php` спершу перевіряє, чи піднятий MySQL.
Якщо ні — виводить `[skip]` з підказкою підняти `docker compose`, а не падає
незрозумілою помилкою з'єднання.
