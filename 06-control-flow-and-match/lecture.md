# 06. Керуючі конструкції та `match`

> Що ти вже вмієш: `if`/`switch`/цикли з іншої мови · Що додає ця тема: `match` (PHP 8.0),
> реальну поведінку `switch`, і специфіку `foreach` за посиланням · ~20 хв

## 1. Якщо ти прийшов з JS / Python / Java

- `switch` у PHP, як і в JS/Java (до `switch`-виразів у сучасній Java), має
  **fallthrough за замовчуванням** — без `break` виконання "провалюється" в
  наступний `case`. Python не має `switch` взагалі (там `match` зʼявився в 3.10
  і теж без fallthrough — ближче до PHP `match`, ніж до PHP `switch`).
- PHP `match` (8.0) — це вираз (повертає значення), схожий на Python `match`/Rust
  `match`, і **не має fallthrough** — кожен `case` (тут "arm", рамка) ізольований.
- `foreach` у PHP може ітерувати **за посиланням** (`foreach ($arr as &$item)`) —
  це змінює оригінальний масив під час ітерації. Такого прямого еквіваленту немає
  в `for...of` (JS) чи Python `for` без явного індексування.

## 2. Ключові терміни

- **`match` expression (вираз match)** — конструкція PHP 8.0, аналог `switch`,
  але вираз (has a value), строге порівняння (`===`), без fallthrough, кидає
  `UnhandledMatchError`, якщо жоден варіант не підійшов і немає `default`.
- **Fallthrough (проваджування)** — виконання наступного `case` без явного `break`.

## 3. Теорія

### 3.1 `if`/`elseif`/`else`

Синтаксично як у більшості C-подібних мов. PHP додатково має альтернативний
синтаксис для шаблонів (HTML упереміш з PHP):

```php
<?php if ($isLoggedIn): ?>
    <p>Привіт!</p>
<?php else: ?>
    <p>Увійдіть</p>
<?php endif; ?>
```

Цей синтаксис (`if: ... else: ... endif;`) практично не використовується в чистому
PHP-коді, але типовий у файлах шаблонів — розпізнавай його, коли побачиш.

### 3.2 `switch`: fallthrough

```php
switch ($status) {
    case 'draft':
    case 'pending':               // fallthrough — обидва case ведуть в один блок
        echo 'Не опубліковано';
        break;
    case 'published':
        echo 'Опубліковано';
        break;
    default:
        echo 'Невідомий статус';
}
```

`switch` порівнює **нестрого** (`==`), що для типів на кшталт `0`/`'0'`/`false`
може дати несподіваний збіг — ще одна причина віддавати перевагу `match`.

### 3.3 `match`: вираз, не інструкція

```php
$label = match ($status) {
    'draft', 'pending' => 'Не опубліковано',   // кілька значень через кому — без fallthrough
    'published' => 'Опубліковано',
    default => 'Невідомий статус',
};

// Без default і без збігу — кидає UnhandledMatchError:
$x = match (5) {
    1 => 'one',
    2 => 'two',
};   // Error!
```

`match` порівнює **строго** (`===`) — ще одна причина, чому він безпечніший за
`switch`.

### 3.4 `match(true)`: патерн для діапазонів

`match` порівнює значення точно, тому для діапазонів/умов використовують
`match (true)`, де кожен arm — це булевий вираз:

```php
$grade = match (true) {
    $score >= 90 => 'A',
    $score >= 75 => 'B',
    $score >= 60 => 'C',
    default => 'F',
};
```

### 3.5 Цикли та `foreach` за посиланням

```php
$numbers = [1, 2, 3];

foreach ($numbers as $n) {
    $n *= 2;              // не змінює оригінальний масив — $n це копія
}
// $numbers все ще [1, 2, 3]

foreach ($numbers as &$n) {
    $n *= 2;               // &$n — посилання, змінює оригінал
}
unset($n);                   // ОБОВ'ЯЗКОВО прибрати посилання після циклу (розділ 4)
// $numbers тепер [2, 4, 6]
```

### 3.6 `break N` / `continue N`

```php
foreach ($matrix as $row) {
    foreach ($row as $cell) {
        if ($cell === 0) {
            continue 2;   // пропустити решту ВНУТРІШНЬОГО і ЗОВНІШНЬОГО циклу за раз
        }
    }
}
```

Числовий аргумент `break`/`continue` — рівень вкладеності, на скільки циклів
"назовні" діяти. Використовується рідко, але корисно знати, читаючи чужий код.

## 4. Підводні камені

- **Забутий `unset()` після `foreach (&$item)`** — класичний PHP-баг: посилання
  `$n` лишається "живим" після циклу, і наступний `foreach ($numbers as $n)`
  **тихо перезаписує** останній елемент масиву значенням передостаннього.
  Завжди `unset($n);` одразу після циклу з посиланням.
- `switch` з нестрогим порівнянням: `case 0:` може спрацювати для `$x = 'abc'`
  у PHP 7 (в PHP 8 це виправлено так само, як `==` в темі 03, але `switch`
  все одно нестрогий за своєю природою — на відміну від `match`).
- `match` без `default` і без збігу **кидає виняток**, а не повертає `null` —
  це свідоме рішення дизайну (явна помилка краща за тиху `null`).

## 5. Сучасний PHP 8.3+

`match` — одна з найпомітніших сучасних фіч PHP 8: коротший, безпечніший
(строге порівняння) і функціональніший (вираз, не інструкція) за `switch`.
У новому коді `switch` вживають дедалі рідше — переважно там, де потрібен
fallthrough або side-effects у кожній гілці без єдиного значення на виході.

## 6. Контекст екосистеми

`match(true)` (розділ 3.4) — поширений патерн у валідаторах і сервісах
Laravel/Symfony для каскаду умов, який раніше писали як довгий `if/elseif`.
