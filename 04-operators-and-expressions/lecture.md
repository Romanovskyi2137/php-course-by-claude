# 04. Оператори та вирази

> Що ти вже вмієш: арифметичні/логічні оператори з іншої мови · Що додає ця тема:
> PHP-специфічні оператори (`??`, `??=`, `<=>`, `.`) і пастки пріоритету · ~15 хв

## 1. Якщо ти прийшов з JS / Python / Java

- Конкатенація рядків — окремий оператор `.` (крапка), не `+` (як у JS/Python).
  `1 + '1'` в PHP — це **арифметика** (`2`), а не конкатенація.
- Немає `//` для цілочисельного ділення, як у Python — для цього функція `intdiv()`.
  `/` завжди повертає `float`, якщо ділення не націло.
- `??` (null coalescing) схожий на `??` у JS, але в PHP він перевіряє саме `isset()`-
  семантику (працює навіть якщо змінна взагалі не існує, без warning) — зручніше за
  `||` у старому JS-стилі, і схоже на `?.`/`??` в сучасному TS.

## 2. Ключові терміни

- **Null coalescing operator `??`** — повертає лівий операнд, якщо він не `null`
  (і не викликає warning, якщо змінної/ключа взагалі не існує), інакше — правий.
- **Null coalescing assignment `??=`** — `$x ??= $y;` еквівалентно `$x = $x ?? $y;`.
- **Spaceship operator `<=>`** — тристороннє порівняння, повертає `-1`/`0`/`1`.

## 3. Теорія

### 3.1 Арифметика

```php
7 / 2;        // 3.5 (float)
intdiv(7, 2);  // 3 (int, ділення націло)
7 % 2;         // 1 (залишок)
2 ** 10;        // 1024 (піднесення до степеня)
-7 % 3;          // -1 — знак результату як у діленого, не як у Python
```

### 3.2 Конкатенація

```php
$name = 'Ada';
echo 'Привіт, ' . $name . '!';   // 'Привіт, Ada!'
echo 1 . 2;                        // '12' — числа приводяться до рядків
echo 1 + '2px';                     // TypeError у strict-контексті виразів PHP 8;
                                     // поза strict_types — 3 з deprecation warning
```

У PHP 8 змінився пріоритет `.` відносно `+`/`-`: тепер `.` має **нижчий** пріоритет,
тому `"Sum: " . $a + $b` парситься як `"Sum: " . ($a + $b)`, а не `("Sum: " . $a) + $b`
(як було в PHP 7 — і це масово ламало код при апгрейді).

### 3.3 `??` та `??=`

```php
$config['timeout'] ?? 30;              // 30, якщо ключа немає або він null — без warning
$config['timeout'] ??= 30;              // записує 30 в $config['timeout'], якщо його не було

// Порівняй з || — || перевіряє truthiness, а не isset:
$count = 0;
$count ?? 10;   // 0 — бо $count не null, і isset() тут не питання
$count ?: 10;    // 10 — ?: (Elvis-оператор) перевіряє truthy, а 0 falsy!
```

`??` і `?:` — різні оператори з різною семантикою: `??` про "чи є значення взагалі
(і не null)", `?:` про "чи truthy".

### 3.4 Пріоритет операторів: типові пастки

```php
$a = true;
$b = false;
$result = $a && $b || true;    // && має вищий пріоритет за ||: (($a && $b) || true)

echo "Result: " . 1 + 2;         // PHP 8: "Result: " . (1 + 2) = "Result: 3"
```

Коли є сумніви — дужки дешевші за годину дебагу.

### 3.5 Побітові оператори (коротко)

```php
5 & 3;   // 1  (AND)
5 | 2;    // 7  (OR)
5 ^ 1;     // 4  (XOR)
~5;         // -6 (NOT)
1 << 3;      // 8  (зсув вліво)
```

У повсякденному веб-коді трапляються рідко (прапорці опцій, низькорівневі задачі);
не плутай `&` (побітовий AND) з `&&` (логічний AND) чи `&$var` (посилання, тема 07).

## 4. Підводні камені

- `.` і `+`/`-` в одному виразі без дужок — класична пастка при міграції з PHP 7,
  де пріоритет `.` був іншим (розділ 3.2).
- `??` не замінює `isset()` там, де потрібно розрізнити "немає ключа" і "ключ = null" —
  для цього дивись тему 03, `key_status()`.
- `?:` (Elvis) і `??` виглядають схоже, але перевіряють різні речі — `0`, `''`, `'0'`
  falsy для `?:`, але не `null` для `??`.

## 5. Сучасний PHP 8.3+

`??=` (PHP 7.4+) — стандартний спосіб задавати значення за замовчуванням для масивів
конфігурації, вживається повсюдно в сучасному коді замість `if (!isset($x)) { $x = ...; }`.

## 6. Контекст екосистеми

Конфігураційні масиви в Laravel/Symfony (`config/app.php` тощо) активно
використовують `??`/`??=` саме через їхню "тиху" поведінку на відсутніх ключах —
критично, коли конфіг частково заповнений з `.env`.

2. Що поверне `intdiv(-7, 2)` і чим це відрізняється від Python `-7 // 2`?
3. Як змінився пріоритет `.` відносно `+` між PHP 7 і PHP 8?
