# 07. Функції та декларації типів

> Що ти вже вмієш: оголошення функцій з дефолтами й типами з іншої мови · Що додає ця тема:
> PHP-специфіку — union/nullable типи, передачу за посиланням, `static`-змінні · ~20 хв

## 1. Якщо ти прийшов з JS / Python / Java

- PHP функції — **не first-class у тому ж сенсі, що в JS/Python за замовчуванням**:
  іменована функція `function foo() {}` реєструється в глобальному просторі функцій,
  а не є значенням змінної. Щоб передати функцію як значення, потрібен `Closure`
  або рядок з іменем (тема 08).
- Типи параметрів і повернення — опційні (як у Python type hints, на відміну від
  обов'язкової типізації TypeScript/Java), але при `declare(strict_types=1)`
  вони **реально перевіряються й кидають виняток** під час виконання (не лише
  статичний аналіз, як у неперевіреному Python type hint).
- `&$param` (передача за посиланням) — це не покажчик C/C++ і не `ref` C#, а
  окремий механізм: параметр стає **аліасом** на оригінальну змінну виклику.

## 2. Ключові терміни

- **Nullable type (`?T`)** — тип, що дозволяє значення `T` або `null`: `?int`
  еквівалентно `int|null`.
- **Union type (`T1|T2`)** — параметр/повернення може бути одним із кількох типів
  (PHP 8.0+).
- **`never` return type** — функція ніколи не повертає значення нормально: або
  завжди кидає виняток, або завжди завершує процес (PHP 8.1+).
- **Pass by reference (передача за посиланням)** — `&$param` робить параметр
  аліасом оригінальної змінної, зміни всередині функції видно й ззовні.

## 3. Теорія

### 3.1 Базовий синтаксис і дефолтні значення

```php
function greet(string $name, string $greeting = 'Привіт'): string
{
    return "{$greeting}, {$name}!";
}

greet('Ada');              // 'Привіт, Ada!'
greet('Ada', 'Вітаю');       // 'Вітаю, Ada!'
```

Дефолтні значення мають бути константними виразами (можна `10 + 5`, не можна
результат виклику функції — крім кількох винятків типу `new` з PHP 8.1).

### 3.2 Nullable і union типи

```php
function findUser(int $id): ?array          // масив АБО null
{
    return $id === 1 ? ['id' => 1] : null;
}

function normalize(int|string $value): string   // приймає int або string
{
    return (string) $value;
}

function process(mixed $value): int|float|null { /* ... */ }
```

### 3.3 `void` і `never`

```php
function logMessage(string $msg): void
{
    echo $msg;
    // return; можна, але без значення. return $x; — помилка компіляції.
}

function fail(string $reason): never
{
    throw new \RuntimeException($reason);   // функція гарантовано не повертає керування
}
```

### 3.4 Передача за посиланням

```php
function increment(int &$value): void
{
    $value++;
}

$x = 5;
increment($x);
echo $x;   // 6 — оригінальна змінна змінилась
```

Використовується рідко в сучасному коді (частіше повертають нове значення), але
трапляється у вбудованих функціях: `sort(&$array)`, `preg_match(..., &$matches)`.

### 3.5 `static`-змінні всередині функції

```php
function nextId(): int
{
    static $id = 0;   // ініціалізується один раз, зберігає значення між викликами
    return ++$id;
}

nextId();   // 1
nextId();   // 2
nextId();   // 3
```

На відміну від локальних змінних (розділ 1), `static` **переживає** виклики
функції — це прихований стан, схожий на модульний рівень у Python, і його варто
використовувати обережно (важче тестувати, неявний стан).

### 3.6 `strict_types` і повернене значення

`strict_types` перевіряє не лише аргументи, а й **тип, що повертається**:

```php
declare(strict_types=1);

function getCount(): int
{
    return '5';   // TypeError! навіть повертане значення перевіряється строго
}
```

## 4. Підводні камені

- Дефолтне значення параметра обчислюється **один раз, на етапі визначення
  функції**, не на кожному виклику (на відміну від Python, де мутабельний дефолт —
  відома пастка `def f(x=[])`; у PHP такої пастки з масивами немає, бо PHP-масиви
  копіюються за значенням — тема 09).
- `static`-змінні — прихований стан, який легко забути: функція виглядає чистою
  (без сторонніх ефектів), але насправді ні. Уникай без вагомої причини.
- Параметр за посиланням `&$x` **не можна** передати літерал чи вираз —
  тільки змінну: `increment(5)` — помилка, `increment($x)` — ок.

## 5. Сучасний PHP 8.3+

Типізовані параметри/повернення + `strict_types` — де-факто стандарт нового коду.
`never` (8.1) корисний для функцій-хелперів на кшталт `fail()`/`abort()` — статичні
аналізатори (тема 39) використовують цю інформацію для аналізу недосяжного коду
після виклику такої функції.

## 6. Контекст екосистеми

Фреймворки активно використовують типізовані повернення для автодоповнення в IDE
й для статичного аналізу (PHPStan бачить `?User` і попереджає, якщо ти забув
перевірку на `null` перед використанням).
