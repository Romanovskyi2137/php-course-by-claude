# Checkpoint 3: гостьова книга

Третій checkpoint-проєкт курсу. Мета — зібрати докупи блок D
(веб-фундамент: теми 28-33) у справжній, реально працюючий веб-застосунок:
форма з валідацією, CSRF-захист, сесії й проста аутентифікація адміна.

## Що будуємо

Класичну "гостьову книгу": будь-хто може залишити запис (ім'я +
повідомлення), записи зберігаються в JSON-файлі й показуються списком.
Адмін може залогинитись і видаляти записи. Усе — на голому PHP, без
фреймворків і без бази даних (БД — блок E).

**Дані для входу адміна (лише для локальної розробки):** пароль
`admin123` — див. `data/admin.php`.

## Структура

```
34-checkpoint-3-guestbook-web-app/
  README.md          # цей файл
  task.md             # вимоги, контракт, як перевірити
  data/
    entries.json         # фікстура: початкові записи гостьової книги
    admin.php             # фікстура: хеш пароля адміна
  starter/
    src/classes.php         # ТУТ ти пишеш код — DTO, репозиторій, функції з TODO
    public/
      index.php               # готовий код — список записів + форма (не редагуй)
      submit.php               # готовий код — обробка нового запису (PRG)
      login.php                 # готовий код — вхід адміна
      logout.php                 # готовий код — вихід адміна
      delete.php                  # готовий код — видалення запису (лише адмін)
  solution/
    src/classes.php                # референсний розв'язок
    public/                          # той самий готовий код
  check.php                            # автоматична перевірка src/classes.php
```

## Як працювати

1. Прочитай `task.md`.
2. Редагуй `starter/src/classes.php`.
3. Перевіряй: `php check.php`.
4. Коли `check.php` зелений — запусти реальний застосунок:
   ```bash
   php -S localhost:8000 -t starter/public
   ```
5. Відкрий `http://localhost:8000/`, залиш запис, залогинься як адмін
   (`admin123`) і видали якийсь запис.
6. Порівняй з `solution/`, заціни чекбокс у `CURRICULUM.md`, зроби коміт.

Запуск застосунку записує нові/видалені записи прямо у `data/entries.json`
— це очікувано (справжня персистенція, тема 26), не помилка.
