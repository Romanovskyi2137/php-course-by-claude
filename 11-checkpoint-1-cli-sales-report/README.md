# Checkpoint 1: CLI-звіт по продажах

Перший checkpoint-проєкт курсу. Мета — не вивчити щось нове, а зібрати
докупи все з блоку A (теми 01-10): функції, типи, рядки/UTF-8, масиви,
керуючі конструкції, замикання — в один невеликий, реально працюючий
інструмент командного рядка.

Жодного ООП тут навмисно немає — це тема блоку B. Весь проєкт — чисті
функції, що працюють з масивами, плюс тонкий скрипт-обгортка для CLI.

## Що будуємо

CLI-утиліту, яка читає "продажі" з файлу-фікстури, фільтрує їх за
категорією та діапазоном дат, рахує сумарну виручку за категоріями і
виводить вирівняну таблицю в термінал — коректно для кириличних назв
категорій (тема 05, `mb_str_pad`, PHP 8.3+).

## Структура

```
11-checkpoint-1-cli-sales-report/
  README.md          # цей файл
  task.md             # вимоги, контракт, як перевірити
  data/
    sales.php          # фікстура: масив записів про продажі
  starter/
    src/functions.php    # ТУТ ти пишеш код — 5 чистих функцій з TODO
    bin/report.php         # готовий скрипт-обгортка для CLI (не редагуй)
  solution/
    src/functions.php       # референсний розв'язок
    bin/report.php            # той самий скрипт-обгортка
  check.php                    # автоматична перевірка функцій із src/functions.php
```

## Як працювати

1. Прочитай `task.md`.
2. Редагуй `starter/src/functions.php`.
3. Перевіряй: `php check.php`.
4. Коли `check.php` зелений — запусти реальний CLI:
   ```bash
   php starter/bin/report.php
   php starter/bin/report.php --category=Електроніка
   php starter/bin/report.php --from=2026-01-10 --to=2026-01-20
   ```
5. Порівняй з `solution/`, заціни чекбокс у `CURRICULUM.md`, зроби коміт.
