# Завдання 05: рядки та UTF-8

## Мета

1. Впевнено користуватись інтерполяцією та `sprintf`.
2. Зрозуміти на практиці різницю `str*` і `mb_str*` для кириличного тексту.

## Що робимо

Пишемо функції для роботи з текстом, який **обов'язково** містить кирилицю —
щоб різниця між байтовими й багатобайтовими функціями була видна одразу, а не
"колись у продакшні на реальних даних".

## Вимоги

1. `greet(string $name)` повертає рядок `"Привіт, {name}!"` (наприклад, для `'Ада'`
   → `'Привіт, Ада!'`) — через інтерполяцію, не конкатенацію.
2. `char_count(string $text)` повертає кількість **символів** (не байтів) у рядку.
3. `shout(string $text)` повертає текст, приведений до верхнього регістру, коректно
   для кирилиці.
4. `truncate(string $text, int $maxLength)` обрізає текст до `$maxLength` символів
   (не байтів!) і, якщо текст справді був обрізаний, додає в кінець `'…'`
   (символ "три крапки", U+2026). Якщо текст коротший або дорівнює `$maxLength` —
   повертається без змін, без доданого `'…'`.

## Контракт (сигнатури)

```php
function greet(string $name): string
function char_count(string $text): int
function shout(string $text): string
function truncate(string $text, int $maxLength): string
```

## Обмеження

- Файл починається з `declare(strict_types=1);`.
- Усі функції мають коректно працювати на кириличному тексті — використовуй
  `mb_*`-версії функцій (`mb_strlen`, `mb_strtoupper`, `mb_substr`), а не
  байтові (`strlen`, `strtoupper`, `substr`).
- `truncate()` не рахує доданий `'…'` у ліміт `$maxLength` (тобто результат
  обрізаного рядка може бути на 1 символ довшим за `$maxLength` за рахунок `'…'`).

## Бонус (не перевіряється автоматично)

Напиши `slugify(string $text): string`, яка перетворює `'Привіт Світ'` на
щось на кшталт `'privit-svit'` (транслітерація + заміна пробілів на дефіс).
Це нетривіально без регулярок (тема 24) — досить простого мапування літер.

<details>
<summary>Підказка 1</summary>

`mb_strlen($text)` замінює `strlen($text)` там, де важлива кількість символів,
а не байтів.
</details>

<details>
<summary>Підказка 2</summary>

Для `truncate()`: спочатку перевір `mb_strlen($text) <= $maxLength` — якщо так,
одразу поверни `$text` без змін. Інакше — `mb_substr($text, 0, $maxLength) . '…'`.
</details>
